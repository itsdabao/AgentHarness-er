# Phase 4.5 — CLI và Web Simple/Detailed

## Scope đã đồng ý

Người dùng muốn giữ CLI cho thao tác nhanh/debug, thêm Web cho quan sát/kiến trúc.
Web có hai mode trong cùng một ứng dụng, chuyển mode chỉ đổi presentation.
Plan cũ terminal-only ngày 07/09 được mở rộng; giữ slug và các acceptance ID cũ.

## Đã implement

- cli.py: command console, one-shot, JSONL, verbose và input thread không chặn polling.
- observation.py: cursor/dedup và terminal-event drain dùng RPCClient hiện có.
- web/index.html, style.css, client.js, app.js: giao diện local, view toggle,
  public JSON, nhóm tool events, sơ đồ ownership, cancel và reattach.
- web_routes.py/rpc.py: static assets cùng origin, CSP, từ chối cross-origin RPC.
- rpc_client.py: lỗi rejection có code riêng để không nhầm với lost response.
- pyproject.toml: minder-cli entrypoint và static package data; không thêm dependency UI.
- Tests: Python client contracts, JavaScript thuần chạy Node, reuse socket/MCP fixture.
- docs/guides/interfaces.md: setup, CLI/Web usage, giới hạn và bằng chứng còn thiếu.

Không sửa agent loop, provider, MCP executor, schema SQLite hoặc .env.
Skill sites-building hướng UI vào working surface, giữ stack và scope local; không
tạo hosted Site, frontend framework hay WebMCP execution surface ngoài yêu cầu.

## Khác đề xuất ban đầu

Không xây hai web app hoặc hai backend. Chỉ lưu preference mode, không lưu trace
bền vững trong browser. Sơ đồ highlight theo event, không phải tracing từng hàm.
Dùng daemon stdin reader cho Windows, không kéo thêm full-screen TUI framework.
Đọc nhanh ẩn record attempt trùng; verbose/JSON vẫn giữ dữ liệu inspect.
